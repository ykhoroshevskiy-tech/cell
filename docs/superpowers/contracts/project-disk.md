# Contract: Project Disk Layout

**Phase**: 1 | **Normative for**: `internal/stage/repo.go`, `internal/sync/pull.go`

## Image build (host)

Input: staged directory tree rooted at temporary `root/` (ext4 root = project disk root):

```text
root/
├── …                          # cp -a from staged repo (files at disk root)
├── .filter-staged             # marker: single line "ok\n"
└── .filter/
    └── authorized_keys        # session ed25519 public key
```

Command sequence:

```text
# 1. assemble root/ (repo first — StageRepository recreates destDir)
stage staged-repo → root/
write root/.filter-staged
write root/.filter/authorized_keys
# 2. image
truncate -s {size_mb}M project.ext4
mkfs.ext4 -d root project.ext4
```

Default `{size_mb}` = 1024 (from `CellConfig.ProjectDiskSizeMB`).

## Guest mount

| Host device | Guest device | Mount point | Mode |
|-------------|--------------|-------------|------|
| project.ext4 drive | `/dev/vdb` | `/project` | rw |

Staged repo path: `/project` (= `REPO_DIR` = `CellConfig.GuestRepoDir` = mount root). There is NO nested `workspace/` subdirectory on the disk.

## Marker

File: `/project/.filter-staged`

- MUST exist after successful stage
- Content: `ok\n` (exact)
- Guest-init MUST fail if missing

## `.filter/` directory (on project disk)

```text
/project/.filter/
├── authorized_keys            # required; sshd AuthorizedKeysFile
├── resolv.conf                # optional; bind-mount to /etc/resolv.conf
└── agent-home/                # bind-mount → /home/agent
    ├── .zshenv                # generated by guest-init
    ├── .cache/
    ├── .config/
    └── .local/share/          # agent app data
```

## Staging source

`launch --repo PATH` accepts a **local directory path** (copied with exclusions below). Git URL clone is NOT the primary path — the operator points at their working repo. Copy via `cp -a` respecting exclusions; do not invoke `git clone`.

## Staging exclusions

When copying repo → staged dir, skip path segments matching any of:

```text
__pycache__, .venv, node_modules, .pytest_cache, session-data, images
```

When `includeGit=false`, skip `.git` entirely.

## Size budget rules

1. Agent binary MUST NOT be written under `.filter/agent-home/` or repo tree
2. Large host artifacts (VM images, firecracker binary) MUST NOT be staged
3. Operator MAY set `CELL_INCLUDE_GIT=0` to omit `.git` from repo copy

## SSH key embedding

`authorized_keys` contains exactly the public key generated for this session. MUST be non-empty; bootstrap MUST fail if no valid public key is available. Guest sshd config (rootfs) sets:

```text
AuthorizedKeysFile /project/.filter/authorized_keys
```

## Inverse sync (host pull)

Normative for: `internal/sync/pull.go`

After launch, operator MAY pull guest repo back to host (auto or manual):

```text
rsync -av [-n] [--delete] \
  -e "ssh -i {key} -o IdentitiesOnly=yes -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null" \
  {ssh_user}@{guest_ip}:{guest_repo_dir}/ \
  {dest}/
```

`-o IdentitiesOnly=yes` prevents "Too many authentication failures" when the operator has many SSH agent keys.

| Rule | Value |
|------|-------|
| Source path | `CellConfig.GuestRepoDir` + `/` |
| Default dest | `SessionRecord.RepoSource` |
| Always exclude | `.filter-staged` |
| Never source | `/project/.filter/**` (outside repo tree) |
| Preconditions | VM running, SSH up, rsync on host and guest |
| Auto-pull interval | 30 seconds (goroutine) |
